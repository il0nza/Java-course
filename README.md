### Задача 7
#### Текст задачи
Дана сигнатура метода: `public bool isInRange (int a, int b, int num);` Метод принимает левую и правую границу (a и b) некоторого числового диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал true, если num входит в указанный диапазон (включая границы). Обратите внимание, что отношение a и b заранее неизвестно (неясно кто из них больше, а кто меньше)

Пример 1: a=5 b=1 num=3

Пример 2: a=2 b=15 num=33

Т.к. отношение границ a и b заранее неизвестно (неясно, какое из них меньше, а какое больше), в коде используется условная конструкция if-else. Метод проверяет, какое из чисел является фактической левой границей. Если a < b, то диапазон проверяется условием num >= a && num <= b. Иначе границы меняются местами: num >= b && num <= a.

На каждом шаге текущее значение i приводится к строке, добавляется разделительный пробел и результат добавляется к итоговой строке.

Пример 1: x=3

```*
  *
 **

```

Пример 2: x=4

Результат:
```*
   *
  **
 ***

Потом идет цикл, который печатает ровно i символов * для текущей строки. В конце каждой итерации внешнего цикла осуществляется переход на новую строку.
