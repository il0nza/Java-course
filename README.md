## Задача 7 Непустые Имена
### Текст задачи
Измените сущность Имя из задачи 1.4.5. Гарантируйте, что:

• Как минимум один параметр будет иметь не null значение и не пустую строку.

• Имя неизменяемо.

Продемонстрируйте работоспособность решения на примерах.

### Алгоритм решения
1. Для обеспечения неизменяемости объекта все три приватных поля (lastName, name, surname) объявлены с модификатором final, а все сеттеры (setName, setLastName, setSurname) полностью удалены из класса
2. Добавлен вспомогательный приватный метод isEmpty(String str), который проверяет строку на null и пустоту с учетом пробелов (str.trim().isEmpty())
3. В основной конструктор Name(String firstName, String lastName, String surname) добавлена валидация входных данных: если все три параметра одновременно являются пустыми или равны null, выбрасывается непроверяемое исключение IllegalArgumentException (наследник RuntimeException) с описанием ошибки
4. В методе toString() сборка строки переведена на StringBuilder с вызовом .trim(), чтобы не создавать лишние промежуточные строки в памяти и убрать лишний пробел в конце
5. В main выполнен автоматический тест с передачей null и пустых строк в блок try-catch, а также организован ручной ввод имен с клавиатуры с перехватом исключений

## Задача 8 Человек меняется
### Текст задачи
Измените сущность Человек из задачи 1.4.6. Новые требования включают:

• Рост человека всегда положительный и не более 500, его можно изменить и получить в любой момент.

• Отца возможно задать только при создании и в дальнейшем он не изменяется, но его можно получить

• Имя можно получить в любой момент в виде объекта типа Имя.

Продемонстрируйте работоспособность решения на примерах

### Алгоритм решения
1. Для запрета изменения отца после создания объекта поле father объявлено с модификатором final, а метод setFather() удален. Для получения ссылки на отца оставлен только геттер getFather()
2. В метод setHeight(int height) добавлена проверка корректности роста: если переданное значение меньше или равно 0, либо больше 500, выбрасывается исключение IllegalArgumentException. В конструкторе установка роста происходит через вызов этого же сеттера, чтобы не дублировать проверки
3. Поскольку класс Name стал неизменяемым, логика наследования фамилии и отчества от отца в конструкторе Person переработана: вместо вызова сеттеров у старого объекта формируется и сохраняется новый экземпляр Name.
4. В конструктор также добавлена проверка, что переданный объект Name не равен null, а метод getName() возвращает ссылку на неизменяемый объект Name.
5. В main реализовано создание списка людей с выбором отца из ранее введенных объектов, проверка работы геттеров getName() и getFather(), а также тестирование изменения роста через setHeight() с перехватом IllegalArgumentException
