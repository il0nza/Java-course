# Задание 1
## Задача 3 Имена
### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:

• Клеопатра

• Пушкин Александр Сергеевич

• Маяковский Владимир

Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.
### Алгоритм решения
1. Объявляем три приватных строковых поля для хранения фамилии, имени и отчества.
2. Создаем основной конструктор, принимающий три параметра. Меньшие конструкторы (с 1 и 2 параметрами) перенаправляют вызов в основной с помощью this(...), передавая недостающие свойства как null.
3. В методе toString() заводим пустую строку-результат. Поочередно проверяем каждое поле с помощью if. Если поле не равно null и не является пустым, приклеиваем его к общему тексту через пробел.

3. Реализуем метод toString(). Внутри него мы вызываем name.toString() и приклеиваем к ней текущий рост человека.

## Человек с родителями
### Текст задачи
Измените сущность Человек из задачи 2.2 добавив ему возможность задавать третий параметр: Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо проверить параметры имени, и в зависимости от ситуации выполнить одно из следующих действий:

• Если у данного человека нет фамилии, и есть отец, у которого фамилия задана, то фамилию необходимо сделать такой же как у отца.

• Если у данного человека нет отчества, а у отца есть имя, то необходимо задать отчество как имя отца с добавлением суффикса “ович”.


Затем необходимо выполнить следующие задачи:
1. Создать людей: Чудова Ивана, Чудова Петра, Бориса
2. Сделать Ивана отцом Петра, а Петра отцом Бориса
3. Вывести на экран строковое представление всех троих людей.
4. При желании можно попытаться реализовать систему в более полном виде: предусмотреть разные виды суффиксов отчества в зависимости от окончания имени, а также предусмотреть возможность задавать пол человека и менять суффикс отчества в зависимости от пола.
### Алгоритм решения
1. Добавляем в класс Person новое приватное поле father с типом данных Person (ссылка объекта на самого себя).
2. В конструкторе проверяем, был ли передан объект отца (father != null). Если отец есть, запускаем логику проверки полей ребенка через геттеры и сеттеры класса Name.
3. Если у ребенка фамилия равна null или пустая (isEmpty()), а у отца фамилия заполнена, то ребенку автоматически присваивается фамилия отца.
4. Если у ребенка отсутствует отчество, программа берет личное имя отца (father.getName().getFirstName()) и приклеивает к нему суффикс "ович", автоматически заполняя отчество ребенка.

# Задание 5
## Задача 2 - Кот мяукает
Создайте сущность Кот, которая описывается следующим образом:

• Имеет Имя (строка)

• Для создания необходимо указать имя кота.

• Может быть приведен к текстовой форме вида: “кот: Имя”

• Может помяукать, что приводит к выводу на экран следующего текста: “Имя: мяу!”, вызвать мяуканье можно без параметров.

• Может помяукать Nраз, что приводит к выводу на экран следующего текста: “Имя: мяу-мяу-…-мяу!”, где количество “мяу”равно N.

Создайте кота по имени “Барсик”, и затем пусть он помяукает сначала один раз, а затем три раза.

### Алгоритм решения
1. Метод meow() без параметров сразу выводит в консоль фиксированную строчку вида Имя: мяу!.
2. Метод meow(int n) сначала проверяет число на корректность (если оно меньше или равно 0, выполнение прерывается).
3. Создается базовая строка с именем кота. Запускается цикл for на n итераций. На каждом шаге к тексту приписывается слово "мяу". Внутри цикла ставится условие if (i < n - 1) — если текущее «мяу» не последнее, к нему дополнительно приклеивается дефис "-".
4. После цикла к строке добавляется восклицательный знак, и результат выводится на экран.
